-------------------------程钱超---------------------------


Chassis-B为小车底盘的代码，给被控制的小车的32主板烧录
TongXin-A-zuwang为组网通信中控制另外两个车的主机，不需要运动，不必烧录底盘代码，ID为0x01
TongXin-B-zuwang为组网通信中被控制的一个从机，需要运动，需烧录底盘代码,ID为0x02
TongXin-C-zuwang为组网通信中被控制的一个从机，需要运动，需烧录底盘代码,ID为0x03


组网通信中，A车要传输的ID改为0xFF，即A车给所有的车通信。需要将RF模块设置为组网通信模式，具体参照DL-20使用说明书.pdf
A车发回传地址的指令，B,C车接到指令后，向A发送各自的地址。A车接收到两车传的地址后，便可实现对两车的控制。

点对点通信中，A车要传输的ID改为对应被控制的车的ID即可。将RF模块设置为点对点通信模式，此模式实现A车对B，C任一车的控制（改ID即可）。
